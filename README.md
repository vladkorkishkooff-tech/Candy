# Vlad Portfolio

Статическая премиальная визитка-портфолио для позиционирования Vlad как инженера под ключ: Telegram-боты, AI-интеграции, сайты и автоматизация малого бизнеса.

Визуальный вектор: dark editorial / SEOtalos-inspired, но с собственным смыслом: Vlad собирает связанную инженерную систему вокруг заявки, записи, AI-ответов, CRM/таблиц и запуска. Hero использует декоративную premium-витрину с 3D-звездами, стеклянной глубиной и летящими элементами, а блок процесса показывает stateful-карту этапов.

## Как открыть

Проект не требует сборки и backend.

1. Откройте `index.html` в браузере.
2. Для проверки через локальный сервер:

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

Адрес: `http://127.0.0.1:8000/`.

## Структура

- `index.html` - контент, семантика, data-атрибуты интерактива.
- `css/02-reset.css` - токены, базовые стили, фон, кнопки.
- `css/04-components/` - стили секций.
- `css/05-animations.css` - reveal, cursor, motion.
- `css/06-utilities.css` - мелкие утилиты.
- `js/main.js` - исходная копия runtime.
- `js/main.bundle.js` - runtime, который подключен на странице.
- `AGENTS.md` - правила работы для AI-агентов.
- `project.md` - память проекта.
- `rules.md` - продуктово-техническое ТЗ и QA-чеклист.

## Контентные правила

- Не показывать подробный стек сразу.
- В hero не выводить длинные списки технологий.
- В карточке проекта показывать максимум 3 технологии до раскрытия.
- Подробности размещать в блоках `Подробнее`.
- Не добавлять фейковые клиенты, метрики, гарантии и неподтвержденные обещания.
- Не делать декоративные элементы похожими на кнопки, если они не меняют состояние или не ведут пользователя дальше.

## Проверка перед публикацией

- Desktop `1440x900`: hero выглядит премиально, CTA видна, нет горизонтального скролла.
- Mobile `390x844`: заголовок читается, CTA видна, нет горизонтального скролла.
- Все блоки `Подробнее` раскрываются с клавиатуры.
- Mobile menu открывается/закрывается, Escape работает.
- `prefers-reduced-motion` не требует анимаций для понимания сайта.
- Hero showcase остается декоративным и не содержит fake-контролов.
- Process deck меняет состояние мышью и с клавиатуры.
- В консоли браузера нет ошибок.
- Ссылки Telegram и email работают.
